## 2. ENC_V4 の結果

生argmax と、実際の出荷構成（探索あり）の両方で測りました。

```
生argmax   V4S 0.812   v3s 0.834   差 -0.021
探索あり   V4S 0.877   v3s 0.861   差 +0.016   （基準は +0.03）
```

符号が入れ替わっています。ENC_V4 で足したのは `obs.select`（今どんな選択を求められているか）と
`remainDamageCounter` / `remainEnergyCost`（解決途中の残量）で、これは局面評価＝価値ヘッドに
効く情報です。価値ヘッドを使うのは探索なので、生argmax で測ると効果が出にくいのは筋が通ります。

ただし n=40 では ±0.03〜0.04 のばらつきがあるので、+0.016 は利得の証拠になりません。
**判定できなかった**ということで、良い結果ではありません。基準未達なので提出しません。

同じ v3s を測り直すと 0.854 → 0.834 → 0.861 と振れました。**このゲートは v046 のような
大きな劣化（lucario -0.11）は確実に捉えますが、±0.02 の優劣は判定できません。**
これは今の測定精度の限界として記録しておきます。
