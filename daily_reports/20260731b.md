## 2. ゲート結果と、危うく犯すところだった間違い

```
n=100   D28S 0.846   v3s 0.793   差 +0.053   → 事前基準（+0.03）では合格
n=300   D28S 0.841   v3s 0.825   差 +0.016   → FLAT
```

n=100 の合格はノイズでした。v3s を5回測ると次のようになります。

```
0.793 / 0.825 / 0.834 / 0.854 / 0.861    幅 0.068
```

重み付き合計の標準誤差を計算すると、この幅とぴったり合います。

```
n=100:  片側 ±0.028   差 ±0.040
n=300:  片側 ±0.016   差 ±0.023
```

**当初の合格基準 +0.03 は、この誤差を知る前に決めたもので、n=100 では 0.75σ にしかなりません。**
以後は n=300 を既定にし、+0.05 以上（2σ超）を合格とします。

狙った1マスは両方の測定で動いています。

```
lucario_v2   n=100  0.330 → 0.390 (+0.06)
             n=300  0.430 → 0.467 (+0.04)
```

仕組みとしては機能しています。0.57% では足りなかった、というのが正確な結論です。
