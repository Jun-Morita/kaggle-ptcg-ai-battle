## 4. 静かに劣化する不具合を3件

いずれも例外を握り潰して**合法だが無意味な手**を返す形。クラッシュせず、エラーも出ない。

| 箇所 | 症状 | 見え方 |
|---|---|---|
| `load_ref.py` | 参照エージェントの lazy import 失敗 | 196決定中115で適当な手。3-117 で「我々が圧勝」に見えた |
| `feats.py` | `train_mcts` import 失敗（サンドボックスに無い） | 全カードIDが 0。出荷tar 0.150/0.000/0.100 |
| `build_submission.py` | 連結時に `feats.option_rows` が解決不能 | **全判断がフォールバック**。0勝25敗×3、`err0=0`、スモーク「OK」 |

対策: `gbdt_policy` にフォールバック回数のカウンタを入れ、スモークで **0 を要求**する。
3件目はこれで検出できるようになった。
