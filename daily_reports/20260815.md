## 自己対戦 PPO について

方向としては正しいが、今回の締切には間に合わない。

**正しい理由**: 模倣は教師を超えない。教師以外の信号を持つのは自己対戦だけ。

**間に合わない理由**: 締切まで1日。PPO は1イテレーションで数十万試合、収束にはその何倍も
必要。当たったかの検証もラダーで2〜3日かかる。RL は既に16件の負の結果があり、
08-08 に明示的に棄却済み。

**本当の難所**: 行動空間。返り値が「選択肢インデックスの可変長リスト」（`minCount ≤ len ≤
maxCount`、重複不可）で、局面ごとに選択肢の意味も個数も変わる。標準的な PPO は
固定次元の行動を前提にするので、そのままでは乗らない。報酬が勝敗だけで1試合100手以上
という credit assignment の粗さも重なる。

**2週間あれば組める構成**（部品は揃っている）:

```
初期方策   今の GBDT 方策を教師にネットへ蒸留（ゼロからの BC は exp048(a) で崩壊済み）
リーグ     作成済みの BC クローン5体（ex4 / ebd / dragapult / lucario / ex1）
分散削減   exp052 の CRN（4.66倍）
アンカー   GBDT 方策への KL 制約
```

再走があるなら本命はこれ。
