## 締切までの残り時間の方針（当時の検討、上記で決着）

3本目を出すと**古い方（x4b3）が消えて {v9b, C} になる。**したがって C は x4b3 を
明確に上回るものに限る。field3 は2セル時点で 0.016 のビハインドなので、見送りの公算が高い。

もう一つの選択肢として、**締切直前まで待って2本の差が開いていれば、良い方に寄せる**手がある。

```
v9b に寄せる    3本目に v9b を出す → {v9b, v9b'}          提出1回
x4b3 に寄せる   3本目4本目に x4b3 → {x4b3', x4b3''}       提出2回（両方600から）
```

同一ビルド2引きの期待値は μ + 0.564σ。ただし σ の相当部分がフィールド変化由来で、
締切後は凍結するので、post-deadline の σ は 28 より小さい可能性がある。その場合、
寄せて得られる上積みは 10点前後にとどまる。**差が明確に開いた場合だけ動く。**
